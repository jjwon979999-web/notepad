메모장 사용 방법

이 창은 F1 또는 메뉴의 사용법으로 열고, Esc로 닫아요. 아래 검색창에 궁금한 말(예: 표, 링크, PDF, 휴지통)을 쓰면 관련 항목만 보여요.
빠른 시작화면 구성여러 메모(탭)저장과 복구 파일 메뉴편집 메뉴서식 메뉴형광펜 이모지보기 메뉴번역메모 메뉴로그인·계정프로젝트 링크표이미지·차트·도형파일 첨부 내보내기 비교글자 크기 버튼단축키문제 해결

1. 빠른 시작 (처음 쓰는 분)

  • 빈 화면을 눌러 그냥 입력하세요. 입력을 멈추고 1~2초 뒤 자동 저장되고, 화면 아래 오른쪽에 ✓ 자동 저장됨이 나와요.
  • 처음 열면 로그인 화면이 나와요. 계정을 만들거나 로그인하면 내 메모·프로젝트가 계정별로 따로 보관되고, 로그인이 싫으면 “게스트로 계속”을 누르면 돼요. 맨 위 탭줄의 +를 누르면 새 메모가 열려요. 첫 줄에 쓴 글이 탭 제목이 돼요.
  • 글자를 드래그로 선택한 뒤 서식 메뉴에서 굵게·크기·색을 바꾸고, 형광펜 메뉴에서 색을 눌러 칠해요.
  • 파일로 보관하려면 파일 → 이 기기에 저장, 인쇄용 문서는 파일 → PDF로 다운로드를 쓰세요.
  • 실수로 지웠다면 당황하지 마세요. 파일 → 메모 타임라인에서 몇 분 전 내용으로 되돌릴 수 있어요.

2. 화면 구성

  • 탭줄 (맨 위) : 열려 있는 메모들. 오른쪽 +는 새 메모, 탭의 ×는 닫기, 주황 점 ●은 “저장하지 않은 변경사항”이에요.
  • 메뉴줄 (한 줄) : 파일 · 편집 · 서식 · 형광펜 · 이모지 · 보기 · 번역 · 메모 · 프로젝트 · 사용법. 오른쪽 끝에 글자 크기 − / +와 내 이름이 적힌 계정 메뉴가 있어요. 화면이 좁으면 옆으로 밀어서 봐요.
  • 눈금자 (선택) : 보기 → 눈금자를 켜면 편집 영역 위에 cm 눈금이 나와요.
  • 편집 영역 : 글을 쓰는 곳. 보기 → 쪽 윤곽을 켜면 A4 종이 모양으로 바뀌어요.
  • 첨부 칸 : 파일을 첨부한 메모에만 편집 영역 아래에 나타나요.
  • 상태줄 (맨 아래) : 글자 수 · 줄 수 · 공백 제외 글자 수 · 단어 수, 첨부 개수(📎), 읽기 전용 같은 상태, 화면 배율, 저장 상태가 있어요. 보기 → 상태 표시줄로 숨길 수 있어요.

3. 여러 메모 다루기 (탭)

  • 새 메모 : 탭줄의 +, Ctrl+N, Alt+N, 또는 파일 → 새 메모. 기존 메모는 그대로예요. (브라우저가 Ctrl+N을 먼저 가져가면 Alt+N을 쓰세요.)
  • 탭 제목 : 메모의 첫 줄이 자동으로 제목이 돼요. 길면 탭에서 잘려 보이지만 내용은 그대로예요. 직접 정하려면 이름 변경(탭 더블클릭 / 우클릭 / 메모 메뉴)을 쓰세요. 이름을 비우면 다시 첫 줄이 제목이에요.
  • 탭 우클릭(휴대폰은 길게 누르기) : 이름 변경 · 메모 복제 · 고정 · 앞/뒤로 이동 · 닫기 · 삭제. 탭을 마우스 가운데 버튼으로 누르면 닫혀요.
  • 순서 바꾸기 : 탭 제목을 끌어서 놓으면 돼요. 놓을 자리에 초록 선이 보이고, 순서는 새로고침해도 유지돼요. 모바일은 탭을 길게 눌렀다가 끌거나, 메모 → 탭 앞으로/뒤로(Alt+Shift+←/→)를 쓰세요. 고정한 탭끼리 / 일반 탭끼리만 순서를 바꿀 수 있어요.
  • 복제 : 내용과 첨부 파일을 복사한 독립 메모가 만들어져요. 복사본을 고쳐도 원본은 그대로예요.
  • 고정 : 고정한 메모는 탭줄 맨 앞과 메모 목록 맨 위에 와요.
  • 탭 닫기 : 점(●)이 있으면 [저장하고 닫기] [저장하지 않고 닫기] [취소]를 물어요. 어느 쪽이든 자동 저장된 내용은 남아 있어서 메모 → 메모 목록에서 다시 열 수 있어요. 마지막 탭을 닫으면 새 빈 메모가 자동으로 생겨요. 비어 있는 메모는 닫을 때 남기지 않아요.
  • 메모 목록 (메모 → 메모 목록) : 모든 메모를 카드로 봐요. 제목, 마지막 수정 시간, 앞부분 미리보기가 있고 열기 · 고정 · 복제 · 삭제를 할 수 있어요. 위 검색창은 모든 메모의 제목과 내용을 찾아요. (지금 메모 안에서 찾기는 Ctrl+F)
  • 삭제와 휴지통 : 삭제한 메모는 바로 사라지지 않고 휴지통으로 가요. 메모 → 휴지통 열기에서 복구(제목·내용·첨부·고정·타임라인 그대로), 영구 삭제(확인 후 첨부·타임라인까지 삭제), 휴지통 비우기를 할 수 있어요. 휴지통 안의 메모는 설정한 기간(기본 30일; 7·14·30·60·90일 또는 자동 삭제 안 함) 뒤 자동으로 삭제돼요.
  • 예전 버전에서 쓰던 메모는 지워지지 않고 첫 번째 메모로 옮겨져요.

4. 저장과 복구

자동 저장

  • 입력을 멈추고 1~2초 뒤 이 브라우저(localStorage)에 저장돼요. 같은 브라우저·같은 파일 위치에서 다시 열면 모든 탭과 마지막에 보던 메모가 그대로 나와요.
  • 저장 공간이 부족하면 “자동 저장에 실패했어요”라고 알려줘요. 이미지를 줄이거나 파일로 저장해 두세요.
  • 브라우저 데이터(사이트 데이터)를 지우면 메모도 사라져요. 중요한 글은 HTML로 저장해 백업하세요.

저장(Ctrl+S)과 ● 표시

  • 자동 저장은 항상 되어 있고, Ctrl+S는 “여기까지 저장 완료”로 표시해요(탭의 ●이 사라지고 타임라인에도 한 번 기록).

메모 타임라인 (이전 내용으로 되돌리기)

  • 파일 → 메모 타임라인. 글을 쓰다 멈출 때마다 기록이 메모별로 따로 쌓이고, 메모마다 최근 100개를 보관해요. 최신 기록이 위에 와요.
  • 카드에는 제목, 저장 시간, 앞부분, 글자 수와 최대 대비 %가 있어요. 내용이 갑자기 줄었다면 % 를 보고 지워지기 전 기록을 찾으세요.
  • 미리보기는 지금 내용을 건드리지 않고 그 시점을 보여줘요. 복구는 확인 후 그 내용으로 돌아가며, 복구 직전의 현재 내용도 새 기록으로 남아요. 삭제는 카드 하나, 타임라인 전체 삭제는 이 메모의 기록만 지워요.
  • 새 메모/불러오기/모두 바꾸기/표 행 삭제/창 닫기 직전에도 자동으로 기록을 남겨요.

5. 파일 메뉴

  • 새 메모 (새 탭) Ctrl+N : 새 탭을 만들어요.
  • 이 메모 저장 Ctrl+S : 저장 완료로 표시하고 타임라인에 기록해요.
  • 이 기기에 저장 (HTML · 모든 탭) : 열려 있는 탭을 모두 한 파일에 담아요. 파일을 열면 맨 위에 탭이 나란히 보이고, 탭을 누르면 그 메모 내용이 나와요(Alt+←/→로도 이동, 인쇄하면 탭마다 한 쪽씩). 서식·표·이미지가 그대로이고 파일 이름은 “메모 모음 (N개 탭)”이에요. 탭이 하나뿐이면 그 메모만 일반 웹 문서로 저장돼요. 현재 탭만 저장 (HTML)은 지금 보는 탭 하나만 저장해요.
  • 이 기기에 저장 (TXT · 모든 탭) : 글자만 담은 일반 텍스트로, 탭마다 ==== [1/3] 제목 ==== 줄로 구분해서 차례로 담아요. 표는 탭으로 나뉘고, 체크리스트는 ☐/☑, 이미지는 [이미지]로 바뀌어요. 탭이 하나뿐이면 그 메모만 저장돼요. 현재 탭만 저장 (TXT)은 지금 보는 탭 하나만 저장해요.
  • Word로 저장 (.doc) : 굵게·기울임·밑줄·크기·색·형광펜·정렬·표·링크가 담긴 Word 호환 문서. Word가 “보호된 보기”를 띄우면 [편집 허용]을 누르세요.
  • 한글에서 열 수 있는 문서로 저장 (.htm) : 한글의 파일 → 열기로 여는 웹 문서예요. 진짜 .hwp 파일은 아니고, 연 뒤 “다른 이름으로 저장 → .hwp”로 바꾸세요.
  • 불러오기 (파일 열기) : .html / .txt 파일을 열어요. 지금 메모에 내용이 있으면 [현재 메모에 불러오기](덮어쓰기, 이전 내용은 타임라인에 남음) / [새 메모로 열기] / [취소]를 물어요. “모든 탭”으로 저장한 파일(HTML, 또는 ==== [1/3] 제목 ==== 줄이 있는 TXT)은 “탭 N개로 한꺼번에 불러올까요?”라고 물어서 탭이 그대로 복원돼요.
  • 파일 첨부 : 메모에 파일을 붙여요. (아래 “파일 첨부” 참고)
  • 메모 타임라인 : 자동 저장 기록 보기·복구.
  • 계정에 저장 / 계정에서 불러오기 / 로그아웃 / 로그인 : 파일 메뉴 맨 아래 “계정” 묶음이에요. (아래 “로그인과 계정” 참고)
  • PDF로 다운로드 : 현재 메모를 PDF 파일로 바로 저장해요. (아래 “내보내기 비교” 참고)
  • 인쇄 / PDF 저장 Ctrl+P : 현재 메모만 A4로 프린터에 인쇄해요. 탭·메뉴·상태줄·눈금자·부호 같은 화면 요소는 빠지고, 글이 길면 여러 쪽으로 나뉘며 표 행과 이미지는 쪽 사이에서 잘리지 않게 해요. 다크 모드나 쪽 윤곽, 화면 배율을 쓰고 있어도 인쇄는 항상 흰 종이에 검은 글씨, 100% 크기로 나와요. 인쇄 창의 대상을 “PDF로 저장”으로 하면 글자를 복사할 수 있는 PDF가 돼요.
    인쇄 창 팁 : 형광펜·글자 배경색이 안 나오면 더 보기 → “배경 그래픽” 체크, 용지는 A4, 여백은 “기본”으로 두세요. 실제 프린터 출력은 사용하는 프린터 설정(드라이버)에 따라 달라질 수 있어요.

6. 편집 메뉴

  • 실행 취소 / 다시 실행 / 복사 / 붙여넣기 / 전체 선택 : Ctrl+Z Ctrl+Y Ctrl+C Ctrl+V Ctrl+A. 다른 메모로 옮기면 실행 취소 기록은 이어지지 않아요.
  • 찾기 / 바꾸기 Ctrl+F : 아래에 검색 줄이 나타나요. 찾을 말을 쓰고 Enter(또는 [다음 찾기])로 다음 위치로 이동해요. [바꾸기]는 지금 선택된 한 곳만, [모두 바꾸기]는 전체를 바꾸고 몇 개인지 알려줘요. 대소문자는 구분하지 않아요. Esc로 닫아요.
  • 날짜·시간 넣기 F5 : 커서 위치에 2026-10-04 14:30 형식으로 넣어요.
  • 번역 : 번역 창을 열어요. (번역 항목 참고)

7. 서식 메뉴

글자 모양 — “선택 → 값 고르기 → 확인”

  • 굵게 / 기울임 / 밑줄 : 글자를 드래그로 선택하고 눌러요 (Ctrl+B Ctrl+I Ctrl+U).
  • 글꼴 · 크기 · 글자 색 : 값을 고른 뒤 초록 확인을 눌러야 적용돼요. 선택한 글자에만 적용되고, 선택이 없으면 안내가 떠요.
  • 색이나 형광펜을 한 번 칠하면, 이어서 쓰는 글자는 자동으로 기본색이에요.

문단

  • 정렬 : 왼쪽 / 가운데 / 오른쪽. 커서가 있는 줄(또는 선택한 줄)에 적용돼요.
  • 체크리스트 넣기 : 클릭해서 체크하는 ☐ 칸을 커서 위치에 넣어요. 체크 상태도 저장돼요.

삽입 · 표

  • 이미지 넣기 / 차트 넣기 / 도형 넣기 : (이미지·차트·도형 항목 참고)
  • 표 : 행×열을 입력하고 [넣기]. 행·열 추가/삭제, 칸 합치기·나누기, 행 선택·삭제, 표 테두리 없음/있음 (표 항목 참고)

화면 · 되돌리기

  • 메모장 배경 : 화면 전체 배경색. 다크 모드에서는 글자가 안 보이지 않게 적용하지 않아요.
  • 색·크기 초기값으로 Alt+R : 선택한 글자의 색·형광펜·크기를 처음 상태로 되돌려요(굵게·기울임·밑줄은 유지). 선택이 없으면 이어서 쓰는 글자가 기본 서식이 돼요.

8. 형광펜

  • 방법 ① 선택 후 칠하기 : 글자를 드래그 → 형광펜 메뉴의 큰 색 버튼 클릭.
  • 방법 ② 펜 모드 : 선택 없이 색 버튼을 누르면 커서가 형광펜 모양으로 바뀌고 메뉴의 형광펜 글씨 아래에 그 색 줄이 생겨요. 글자 위를 드래그하면 칠해지고, 한 번 칠하면 자동으로 꺼져요. Esc로도 꺼요.
  • 기본 12색 외에 직접 고르기로 원하는 색을 만들 수 있고, 마지막에 쓴 색은 기억해요. 지우려면 칠한 글자를 선택하고 선택한 글자의 형광펜 지우기를 누르세요.

9. 이모지

  • 검색창에 “하트”, “웃음”, “음식”, “heart”처럼 한글·영어로 검색하고, 누르면 커서 위치에 들어가요. 창이 열려 있어서 여러 개를 연달아 넣을 수 있어요. 약 2,000개가 들어 있어요.
  • Windows에서는 Win+. 키의 기본 이모지 창도 그대로 쓸 수 있어요.

10. 보기 메뉴 (한글(Hancom)처럼 보기)

보기 메뉴의 표시는 화면에서만 달라질 뿐 저장·인쇄·PDF·내보내기 파일에는 영향이 없어요. 설정은 새로고침해도 유지돼요. 켜진 항목에는 ✓가 붙어요.

화면

  • 다크 모드 : 어두운 화면.
  • 쪽 윤곽 (종이 모양) : 회색 책상 위에 A4 종이(가로 794px·세로 1123px 이상)가 놓인 모습으로 보여요. 글이 길어지면 종이가 아래로 늘어나요.
  • 눈금자 : 편집 영역 위에 cm 눈금자를 보여줘요. 초록 세로선이 글이 시작되는 0 위치예요. 화면 배율에 맞춰 간격이 달라져요.
  • 격자 보기 : 20px 간격의 연한 격자를 깔아 줄·간격 맞추기에 도움이 돼요.
  • 상태 표시줄 : 맨 아래 상태줄을 숨기거나 보여요.
  • 전체 화면 (집중 모드) : 탭·메뉴·상태줄을 숨기고 글쓰기에만 집중해요. Esc로 나와요.

확대 / 축소

  • 화면 확대 / 화면 축소 / 100%로 되돌리기 또는 아래 상태줄의 배율 상자(50%~300%)에서 고르세요. 글 내용은 바뀌지 않고 보이는 크기만 달라져요.

표시 (한글식 보기)

  • 문단 부호 : 문단이 끝나는 곳과 줄 바꿈, 빈 줄에 파란 ↵ 표시를 해요. 엔터를 몇 번 눌렀는지, 빈 줄이 있는지 한눈에 볼 수 있어요.
  • 조판 부호 : 문단 부호에 더해 띄어쓰기는 ␣, 탭은 →, 줄 바꿈 안 되는 공백은 °로 보여주고, 표·그림·차트·도형 위에 [표] [그림] [차트] [도형] 이름표를 달아요. 공백이 두 칸 들어갔는지 찾을 때 좋아요. (화면에 보이는 부분만 표시해요.) 부호가 작아 보이면 보기 → 부호 크기 바꾸기를 누를 때마다 보통 → 크게 → 아주 크게로 바뀌어요. (기본은 “크게”, 다크 모드에서는 밝은 색으로 나와요.)
  • 투명 선 : 표의 칸 경계를 파란 점선으로, 그림·차트·도형의 테두리를 점선으로 보여줘요. 테두리를 없앤 표(서식 → 표 → 표 테두리 없음/있음)의 칸은 빨간 점선으로 나타나서, 선이 없어도 칸 위치를 알 수 있어요.

편집 상태

  • 자동 줄 바꿈 : 끄면 줄이 옆으로 길게 이어지고 가로 스크롤이 생겨요.
  • 읽기 전용 : 실수로 고치지 않게 잠가요. 읽기 전용에서는 링크를 그냥 클릭해도 열려요.
  • 맞춤법 검사 (브라우저) : 브라우저의 기본 맞춤법 검사를 켜고 꺼요. 한국어 맞춤법을 완벽하게 잡아 주지는 않고, 브라우저에 한국어 사전이 없으면 밑줄이 안 나올 수 있어요(크롬·엣지: 설정 → 언어에서 한국어 추가).
  • 음성으로 읽기 / 중지 : 선택한 글(없으면 전체)을 읽어줘요. 다시 누르면 멈춰요. 컴퓨터에 한국어 음성이 있어야 자연스러워요.

11. 번역

  • 메뉴줄의 번역(또는 편집 → 번역)을 누르면 선택해 둔 글이 들어오고, 선택이 없으면 메모 전체가 들어와요. 창 안에서 글을 고쳐도 돼요.
  • 한국어·영어·일본어·중국어·스페인어·프랑스어·독일어를 지원해요. 원문 언어는 자동 감지(한글·일본어·한자는 정확, 그 외 로마자는 영어로 가정)나 직접 선택할 수 있어요.
  • [번역]을 누르면 원문 → 번역문이 문단 단위로 나란히 나와요. [결과 복사], [메모에 삽입]도 돼요.
  • 무료 서비스(MyMemory)를 써서 인터넷이 필요하고 하루 사용량이 제한돼요. 한도가 차거나 연결이 안 되면 안내가 뜨고 [Google 번역으로 열기]를 쓸 수 있어요. 본인의 키·이메일을 넣으면 한도가 늘어나고(이 브라우저에만 저장), 번역이 안 돼도 메모장은 정상 동작해요.

12. 메모 메뉴

  • 새 메모 / 메모 목록 · 모든 메모에서 찾기
  • 이름 변경 / 메모 복제 / 고정·고정 해제
  • 탭 앞으로 / 탭 뒤로 (Alt+Shift+←/→) : 현재 탭 위치 이동.
  • 이 탭 닫기 (Alt+W) / 이 메모 삭제 (휴지통으로) / 휴지통 열기
  • 현재 메모 내용 비우기 : 지금 메모의 글을 모두 지워요. 내용이 있으면 안내가 뜨고 4초 안에 한 번 더 누르면 비워져요(이전 내용은 타임라인에 남아요).

12-1. 로그인과 계정

  • 처음 열면 로그인 화면이 나와요. 계정 만들기 탭에서 아이디(2~20자 한글·영문·숫자·_ . -)와 비밀번호(6자 이상)를 정하면 계정이 만들어지고 바로 로그인돼요. 로그인 탭에서 없는 아이디를 쓰면 “이 아이디로 계정 만들기” 버튼이 나와서 한 번에 가입할 수 있어요.
  • 계정마다 메모 · 탭 · 타임라인 · 휴지통 · 프로젝트 · 첨부 파일 · 화면 설정(다크 모드·보기 등)이 따로 저장돼요. 다른 계정의 메모는 보이지 않아요.
  • 게스트로 계속을 누르면 로그인 없이 이 기기에 있던 기존 메모를 그대로 써요(예전 버전에서 쓰던 메모가 여기에 있어요). “다음부터 로그인 화면을 건너뛰기”를 체크하면 다음에 묻지 않아요. 나중에 계정 메뉴 → 로그인 / 계정 만들기로 바꿀 수 있어요.
  • 오른쪽 끝 계정 메뉴 : 로그인한 이름 확인, 게스트 메모를 이 계정으로 가져오기(복사, 첨부·타임라인 포함, 원본은 그대로), 비밀번호 변경, 로그아웃, 계정 삭제(비밀번호 확인 후 이 계정의 모든 데이터를 이 브라우저에서 삭제).
  • 계정 보관함 : 파일 → 계정에 저장을 누르면 이름을 정해 열려 있는 탭 모두(또는 지금 탭만)를 내 계정에 보관해요. 탭마다 따로 구분되어 담기고(첨부 파일 제외), 파일 → 계정에서 불러오기에서 저장본 목록을 보고 탭으로 불러오기(탭마다 새 메모로 열려요)나 삭제를 할 수 있어요. 다른 계정에는 보이지 않고, 저장본은 최대 50개까지 보관해요. 두 항목은 로그인했을 때만 쓸 수 있어요(게스트는 흐리게 보이고, 누르면 로그인하라고 안내해요). 파일 메뉴에도 로그아웃이 있어요.
  • “로그인 상태 유지”를 체크하면 브라우저를 닫아도 로그인이 유지되고, 끄면 창을 닫을 때 로그아웃돼요. 비밀번호를 5번 틀리면 30초 동안 잠겨요.
  • 꼭 알아두세요 : 이 로그인은 서버가 없어서 이 브라우저 안에서만 동작하는 “개인 잠금 + 데이터 분리”예요. 비밀번호는 암호화(PBKDF2)해서 저장하지만 메모 내용은 암호화되지 않아요. 다른 기기나 다른 브라우저와는 동기화되지 않고, 비밀번호를 잊으면 복구할 수 없어요. 중요한 글은 HTML로 저장해 백업하세요.

12-2. 프로젝트 (내 메모를 한눈에)

  • 프로젝트는 관련된 메모를 묶는 폴더 같은 거예요. 예: “과학 탐구”, “여행 계획”. 프로젝트는 계정마다 따로 있어요.
  • 프로젝트 → 내 프로젝트 한눈에 보기 : 위쪽에 프로젝트·메모·첨부·휴지통 개수가 나오고, 아래에 프로젝트마다 카드가 나와요. 카드에는 색 띠, 이름, 메모 개수, 최근 수정 시간, 최근 메모 5개의 제목이 있고 제목을 누르면 그 메모가 열려요. 어느 프로젝트에도 안 넣은 메모는 미분류 카드에 모여요. 위 검색창은 프로젝트 이름과 메모 제목·내용을 찾아요.
  • 카드 버튼 : 메모 목록(그 프로젝트 메모만 보기) · + 새 메모(그 프로젝트에 바로 새 메모) · 이름·색(이름과 8가지 색 중 선택) · 삭제(프로젝트만 지우고 메모는 미분류로 옮겨요).
  • 메모를 프로젝트에 넣기 : 프로젝트 → 이 메모를 프로젝트에 넣기, 메모 → 프로젝트에 넣기, 탭 우클릭 → 프로젝트 지정, 메모 목록 카드의 [프로젝트] 버튼. 목록에서 고르거나 “새 프로젝트를 만들어서 넣기”를 쓰세요.
  • 프로젝트에 넣은 메모의 탭 위쪽에는 그 프로젝트 색 띠가 생겨서 탭만 봐도 구분돼요. 메모 목록 위 드롭다운으로 프로젝트별로 걸러 볼 수 있어요.

13. 링크

  • https://…, http://…, www.… 주소를 쓰고 잠시 멈추거나 스페이스·엔터를 누르면 파란 밑줄 링크가 돼요. 주소 뒤에 한글이 붙어도 주소 부분만 링크가 되고, 붙여넣은 주소와 불러온 파일 속 주소도 인식해요.
  • 열기 ① 링크를 클릭하면 아래에 작은 창이 떠요. [열기 ↗]는 새 탭, [주소 복사]는 복사예요. 일반 클릭은 글 편집을 방해하지 않아요. (모바일은 이 방법)
  • 열기 ② Ctrl+클릭(맥은 ⌘)하면 바로 새 탭에서 열려요. 아직 링크가 안 된 주소 글자도 Ctrl+클릭으로 열 수 있어요.
  • 새 탭이 안 열리면 브라우저 팝업 차단이나 미리보기 창 제한 때문일 수 있어요.

14. 표 자세히

  • 넣기 : 서식 메뉴의 표 줄에 행·열 숫자(행 최대 30, 열 최대 12)를 쓰고 [넣기]. 칸을 눌러 바로 쓰면 돼요.
  • 행 보기 : 커서가 있는 칸의 행 전체가 연한 초록색으로 표시돼요.
  • 행 선택 · 삭제 : 칸을 Alt+클릭하거나 서식 → 표 행 선택을 누르면 행이 진한 초록으로 선택돼요. 이때 Delete/Backspace를 누르면 행이 삭제돼요. Esc나 다른 글자를 입력하면 선택이 풀려요. 글자를 고치다가 Backspace로 행이 지워지는 사고를 막으려고 일반 클릭만으로는 삭제되지 않아요. 삭제 직전 상태는 타임라인에 남아요.
  • 행·열 편집 : 행 위/아래 추가, 열 왼쪽/오른쪽 추가, 열 삭제 (커서가 있는 칸 기준).
  • 칸 합치기 / 나누기 : 합치기는 오른쪽 칸과 합쳐요. 합친 칸에서 나누기를 누르면 한 칸씩 풀려요. 합친 표에서는 열 추가·삭제 위치가 어긋날 수 있어요.
  • 표 테두리 없음 / 있음 : 표 선을 없애거나 되살려요. 선이 없어도 보기 → 투명 선을 켜면 칸 위치가 점선으로 보여요.

15. 이미지 · 차트 · 도형

이미지

  • 서식 → 이미지 넣기(여러 장 가능), Ctrl+V 붙여넣기(스크린샷 등), 또는 Shift를 누른 채 파일 끌어놓기. 큰 사진은 가로 1280px 정도로 자동으로 줄여 저장 공간을 아껴요.
  • 크기 조절 : 이미지를 클릭하면 초록 테두리와 조절 창이 떠요. 슬라이더(5~100%), px 숫자 입력(Enter로 적용), 25/50/75/100% 버튼, 오른쪽 아래 초록 동그라미 끌기(비율 유지), [원래]와 [삭제]가 있어요.

차트 (막대 · 꺾은선)

  • 서식 → 차트 넣기 → 종류·색상(4가지)·크기를 고르고 데이터를 쉼표로 써요. 첫 줄은 이름 줄, 다음 줄부터 항목,값,값… (값 열 최대 4개). 제목, 값 표시, 범례, 격자선을 바꾸면 미리보기가 바로 바뀌어요.

  • 넣은 차트는 클릭하면 크기 조절, 더블클릭하면 데이터 수정이에요.

도형

  • 사각형·둥근 사각형·원/타원·삼각형·마름모·오각형·별·화살표·선·말풍선·하트. 채우기(없음 가능)·테두리 색/두께·너비/높이·안에 넣을 글자(색·크기)를 정해요. 더블클릭으로 수정해요.

16. 파일 첨부 (메모마다 따로)

  • 파일 → 파일 첨부, 아래 상태줄의 📎 버튼, 첨부 칸의 [+ 파일 추가]로 고르세요. 종류 제한 없이 150MB까지 가능해요.
  • 끌어다 놓기 : 파일을 화면 위로 끌면 “파일을 여기에 놓으세요” 표시가 나타나고, 놓으면 현재 메모에 첨부돼요. 이미지를 첨부 대신 본문에 넣으려면 Shift를 누른 채 놓으세요. 탐색기에서 복사한 파일을 Ctrl+V로 붙여넣어도 첨부돼요.
  • 첨부는 편집 영역 아래 카드로 보여요 (이름·크기, 이미지는 미리보기). [열기] [다운로드] [삭제], 이미지는 [본문에 삽입]도 있어요. [접기]로 카드 줄을 숨길 수 있어요.
  • 첨부는 메모별로 따로 저장돼요. 다른 메모에 보이지 않고, 복제하면 복사되고, 삭제한 메모를 복구하면 함께 돌아오고, 영구 삭제하면 함께 지워져요.
  • 파일은 브라우저의 IndexedDB에 저장되어 새로고침해도 남고 메모 자동 저장을 느리게 하지 않아요. HTML·TXT·Word·PDF 내보내기에는 포함되지 않아요.

18. 글자 크기 − / + 버튼

  • 메뉴줄 오른쪽 끝의 − 15 +는 선택한 글자의 크기를 1px씩 줄이고 늘려요(8~72px). 가운데 숫자는 커서 위치 글자의 크기예요. 길게 누르면 계속 바뀌고, Alt+↑/Alt+↓로도 돼요.

20. 문제 해결 (자주 묻는 질문)

  • 저장했는데 탭 하나만 들어 있어요. “현재 탭만 저장”이 아니라 이 기기에 저장 (HTML · 모든 탭) 또는 (TXT · 모든 탭)을 쓰세요. 탭이 둘 이상일 때 모든 탭이 담기고, 닫아 둔 탭은 포함되지 않아요(필요하면 메모 목록에서 먼저 여세요). Word·한글용 문서와 PDF는 지금 보는 탭만 만들어요.
  • 로그인 화면이 계속 나와요. “로그인 상태 유지”를 체크하고 로그인했는지, 브라우저가 사이트 데이터를 자동으로 지우는 설정(시크릿 창 포함)이 아닌지 확인하세요. 로그인이 필요 없으면 “게스트로 계속”과 “다음부터 건너뛰기”를 쓰세요.
  • 다른 계정/게스트로 쓰던 메모가 안 보여요. 메모는 계정마다 따로예요. 오른쪽 끝 계정 메뉴에서 로그아웃한 뒤 원래 계정(또는 게스트)으로 들어가세요. 게스트 메모를 계정으로 옮기려면 계정 메뉴 → 게스트 메모를 이 계정으로 가져오기를 쓰세요.
  • 비밀번호를 잊었어요. 서버가 없어서 복구할 수 없어요. 새 계정을 만들거나 게스트로 계속해야 하고, 잠긴 계정의 메모는 이 브라우저에 남아 있지만 열 수 없어요. 비밀번호는 꼭 기억해 두세요.
  • 인쇄했는데 색이 안 나와요 / 여러 쪽이 안 나와요. 인쇄 창의 “배경 그래픽”을 켜세요. 브라우저의 인쇄 미리보기에서 쪽 수를 확인할 수 있어요. 그래도 안 되면 파일 → PDF로 다운로드를 만들어 그 파일을 인쇄하세요.
  • 새로고침했더니 메모가 사라졌어요. 같은 브라우저·같은 파일 위치에서 열었는지 확인하세요. 파일을 다른 폴더로 옮기거나 브라우저 데이터를 지웠다면 저장 공간이 달라져요. 백업해 둔 HTML을 불러오기로 열면 돼요.
  • “자동 저장에 실패했어요”가 떠요. 저장 공간이 가득 찬 경우예요. 큰 이미지를 줄이거나 불필요한 메모를 휴지통에서 영구 삭제하고, 중요한 글은 HTML로 저장하세요.
  • 실수로 지웠어요. 파일 → 메모 타임라인에서 지우기 전 기록을 찾아 복구하세요. 메모를 통째로 지웠다면 메모 → 휴지통 열기에서 복구하세요.
  • Ctrl+N이 안 돼요. 브라우저가 새 창을 여는 데 먼저 쓰는 키예요. Alt+N이나 탭줄의 +를 쓰세요.
  • 링크가 안 열려요. 팝업 차단을 풀어 주세요. 일반 클릭은 링크 창이 뜨고, Ctrl+클릭은 바로 열려요.
  • 번역이 안 돼요. 인터넷 연결과 하루 사용량을 확인하세요. 안 될 때는 [Google 번역으로 열기]를 쓰세요. 번역과 상관없이 메모장은 정상 동작해요.
  • 음성 읽기 소리가 안 나요. 미리보기 창에서는 막혀 있을 수 있어요. 파일을 저장해 크롬·엣지에서 직접 열고, 한국어 음성이 설치돼 있는지 확인하세요.
  • 맞춤법 밑줄이 안 나와요. 브라우저 설정의 언어에서 한국어 맞춤법 검사를 추가해야 해요.
  • 한글에서 파일이 안 열려요. “한글에서 열 수 있는 문서” 파일은 한글의 파일 → 열기에서 파일 형식을 웹 문서(또는 모든 파일)로 두고 여세요. 그래도 안 되면 Word용 .doc로 연 뒤 한글에서 가져오세요.
  • PDF가 안 만들어져요. 일부 브라우저가 이 방식을 막아요. 안내에 따라 인쇄 창의 “PDF로 저장”을 쓰세요.
  • 다른 메모로 옮긴 뒤 Ctrl+Z가 안 돼요. 메모를 바꾸면 실행 취소 기록이 이어지지 않아요. 이전 내용이 필요하면 타임라인을 쓰세요.
  • 다른 컴퓨터에서 이어 쓰고 싶어요. 브라우저마다 저장 공간이 따로예요. HTML로 저장해 옮긴 뒤 불러오기로 여세요. 첨부 파일은 따로 옮겨야 해요.
